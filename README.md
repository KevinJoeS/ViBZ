# VIBZ

VIBZ is a social-product-inspired frontend concept for short-lived, interest-based communities. Users can browse idea rooms, join conversations, create new prompts, save favorites, personalize their feed, and explore niche communities without the noise of traditional social feeds.

## Features

- Auth flow with login and registration
- Personalized vibe onboarding with interest selection
- Discover feed with filters and search
- Explore communities and trending rooms
- Create new VIBZ threads and prompts
- Save and join rooms
- Notifications and profile management
- Responsive layout for desktop and mobile

## Run locally

```bash
cd "D:/Downloads/ViBZ-main/ViBZ-main"
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/ViBZ-main/
```

## Project structure

- `index.html` – app structure and all modal / screen sections
- `style.css` – core layout and responsiveness
- `vibz-polish.css` – visual polish and theme styling
- `script.js` – state, rendering, interactions, auth, and onboarding logic

## Notes

This project is built as a front-end prototype with vanilla HTML, CSS, and JavaScript.
